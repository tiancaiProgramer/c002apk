# c002apk

**当前维护者：[tiancaiProgramer](https://github.com/tiancaiProgramer)**，负责本维护分支的后续开发、新增功能与问题修复。

这是基于 c001apk-compose 的社区维护版，应用现名 **c002apk**。原项目来源、原作者及第三方组件信息集中记录在文末“来源与致谢”和 [AUTHORS.md](AUTHORS.md)。

这是独立的非官方客户端修复版本，与酷安官方及上游作者无隶属或背书关系。包名 `com.example.c001apk.replyfix`，不会覆盖原版 `com.example.c001apk.compose`。

## 修复内容

维护与新增功能：**tiancaiProgramer**。

- 0.1.1 增加图片缓存与显示修复：并发下载互不破坏缓存、复用缩略图缓存、按 EXIF 旋转后的真实尺寸显示、保留“查看原图”入口、改善 Live 图封面到视频的切换。
- 二手交易商品频道使用双列商品卡片，显示封面、发布标题、价格、交易来源和地区；闲鱼标签可打开对应商品链接。话题讨论区保留动态列表。
- 发布构建恢复 R8 与资源精简，APK 从约 22.05 MB 降到约 6.06 MB。原包名和原发布签名支持覆盖更新。
- Token 时间规范化为 `(System.currentTimeMillis() / 1000L).toString()`，不再转换为 float。这是保留的代码改进，不是本次恢复评论的必要条件。
- 保留原 v2 Token 算法。发表评论时，Device 第 0 段读取使用者自己的“数字联盟 ID”设置；Token 输入与实际发送的 Device 一致。
- 保存 ID 时同步更新 Device 首段，保留其余字段，避免随机更换 MAC 或把旧 ID 留在 Device 中。
- 保留原 Cookie、登录流程和评论 Body，包括 `replyAndForward=0`。
- APK 和源码不内置测试者的 ID、Cookie、账号或设备参数。

## 当前状态与使用

最新正式版 [0.1.5](https://github.com/tiancaiProgramer/c002apk/releases/tag/v0.1.5)（versionCode 270）集成图文编辑器，沿用正常包名、原签名及 R8，可保留数据覆盖已有 c002apk。图文编辑与输入体验已通过自动和手动验收；图文发布能力仍属开发预览，实际图片上传、创建、读回及删除尚未完成端到端验收。

### 图文混排编辑器（开发预览）

首页“动态”右下角的“＋”提供“发动态”和“写图文”两个选项，两项之间带细分隔线，菜单右下角对齐加号中心。前者沿用原动态编辑窗口；后者采用连续正文编辑，支持标题、可选题图、在光标处插图、图片说明、段落移动与删除、预览和本机草稿恢复。底部与动态保持相同的五项工具和图标：表情、图片、文件选图、@、话题；页面使用应用现有主题、字号与深色模式设置。

图文正文按内容块顺序提交，不会将所有图片合并为动态附图。图片全部上传完成后才提交发布请求；失败时保留草稿，发布前确认公开或仅自己可见。当前为开发预览，编辑器离线测试与真实服务端发布验收分别记录，详见 [图文发布说明](docs/ARTICLE_EDITOR.md)。

本版包含已验收 `.8` 的输入法和光标修复，正文跟随键盘展开过程移动，避免弹完键盘再滚动。动画专项见 [键盘同步检查](docs/ARTICLE_IME_ANIMATION.md)，滚动对照与验收范围见 [滚动与输入法检查](docs/ARTICLE_SCROLL_PERFORMANCE.md)。

### GitHub 版本更新提醒

从 `0.1.3-rc.1` 起，c002apk 检查本维护者仓库 [GitHub Releases](https://github.com/tiancaiProgramer/c002apk/releases)，识别已发布的正式版和预览版，按版本号选择高于当前安装版且附有正式 APK 的版本。

- 启动时自动检查，成功检查后 6 小时内不重复请求；联网后台任务约每日检查一次。
- 新版本弹窗显示更新说明，可直接打开对应 APK 下载链接或发布详情；后台通知每个版本提醒一次。
- “设置 → 关于 → 检查 c002apk 更新”可随时手动检查。“后台更新通知”可申请通知权限或进入系统通知设置。
- 后台提醒需要允许 c002apk 通知，系统省电策略可能延迟任务；强行停止应用后需再次打开。此功能为定期检查，不是 GitHub 即时推送。
- GitHub 请求使用独立客户端，不携带酷安 Cookie、Token、数字联盟 ID 或设备请求头。连接失败时不打扰正常使用，手动检查会提示重试。

现有“检查已安装应用更新”仍用于手机里的应用，与 c002apk 自身更新入口分开。发布规范和测试方式见 [GitHub 更新说明](docs/GITHUB_UPDATES.md)。

[0.1.4](https://github.com/tiancaiProgramer/c002apk/releases/tag/v0.1.4) 包含平板布局修复：竖屏单列，横屏按可用窗口宽度分栏；旋转或调整窗口时重新判断。横屏导航按窗口可用宽高比例计算位置和间距，适应不同设备及窗口尺寸；比例布局已在平板实测，保留使用者确认的效果。继续包含应用内官方登录、并发评论验证合并、未登录回复提示及此前图片/交易/评论修复，沿用原包名和原签名，可保留数据覆盖更新。当前附件为 versionCode 261，替换本版早期固定间距包；已装同版本旧包的设备请手动下载覆盖。详见 [平板布局说明](docs/TABLET_LAYOUT.md)。

新设备如遇 `err_request_captcha_v2`，会弹出“完成验证以查看评论”，请在手机上手动完成，成功后自动重试。已在新设备验证评论恢复；不会自动解验证码或绕过服务端验证。详见 [新装设备评论验证记录](docs/FRESH_INSTALL_COMMENTS.md)。

### 评论发送配置

这是**需要本人有效 ID 配置的实验版本**，尚未实现自动获取数字联盟 ID。不要把它描述为“所有设备安装即用”。

1. 安装 Release 中的 APK，使用自己的账号登录。
2. 获取本人 ShuzlmID：酷安官方 App → 设置 → 关于 → 右上角三点 → 检测日志 → 连点“复制 OAID”4 下；粘贴复制出的内容，找到其中的 `ShuzlmID`。
3. 在本客户端设置 → 数字联盟 ID 中填入上述 **ShuzlmID**，保存后重新进入动态发布评论。虽然官方入口名为“复制 OAID”，这里需要填写的是日志中的 ShuzlmID，而非 OAID。不要使用别人分享的 ID、Cookie 或 Device。

没有有效标识时，单独修复时间格式仍可能收到 `err_request_need_upgrade_new_version`。任意随机 36 位文本是否有效没有得到验证。Root / Frida 用于开发验证，运行本版本不要求 Root / Frida。

## 验证依据

2026-10-13，使用者补充手动测试：原版 925abdb 保持原时间代码，仅将“数字联盟 ID”设置改为本人从官方检测日志取得的 36 位 ShuzlmID 后，评论成功。因此，在本次设备与账号测试中，此前失败的关键原因是该设置填写了错误标识；正确配置 ShuzlmID 即可恢复回复，无需修改原版时间代码。

同一小米 15、同一账号、网络、动态下的请求对照表明：整数秒时间版仍失败；仅替换 Device 第 0 段并重新生成配套 v2 Token 后成功；仅更换 MAC 段、最后一段或删除 replyAndForward=0 均未解决问题。

详见 [评论测试说明](docs/VALIDATION.md)、[图片与交易验证](docs/DEVICE_VALIDATION.md) 和 [体积分析](docs/SIZE_VALIDATION.md)。评论配置只验证过单一设备/账号组合，未验证跨设备普遍成功，也未完整确定服务端全部判定条件。
