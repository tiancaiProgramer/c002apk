# 键盘与正文动画同步：本地候选 .8

日期：2026-10-28。候选 `0.1.5-article-preview.8` / versionCode 269；仅本地，未推送 GitHub。

使用者已确认 `.7` 的新增文字可见和滑动保留键盘两项正常，但反馈键盘先弹出、正文随后上移。本次仅调整这段动画时序。

## 源码改动

- 将光标显示请求从 IME 高度稳定后等待 200ms 的逻辑中移出，改为在每个键盘高度增加的帧发起请求。
- 在图文面板范围内将 BringIntoView 的独立滚动动画改为 snap，直接跟随 imePadding 已有的动画视口，避免键盘动画后再启动一次正文缓动。
- 保留 `.7` 的焦点段落固定、禁用跨条目 AndroidView 复用、文字改变时光标跟随，以及现有 UI 圆角、按钮、主题、登录与设备配置。
- 增加离线动画时间线用例，记录 IME progress、光标屏幕坐标、窗口尺寸与焦点；排除横屏/前台变化带来的无效测量。预计可见区底部按工具栏高度估算，不作为真实布局边界断言。

## 当前验证状态

正常包与独立 R8 包均构建成功；46 项 JVM 测试通过。两包均不可调试，沿用原发布证书。普通包的图文 Activity 不导出；独立性能测试入口继续由 DUMP 权限保护。

`.8` 已覆盖安装到独立测试包，没有覆盖原版 c001apk 或正常 c002apk。使用者提供竖屏前台时间后，最终离线回归 10 项用例中 9 项通过、1 项假设跳过、0 失败，用时 51.235 秒。跳过的是此前已在 Debug 检查通过的独立加号菜单组件夹具，与优化包的 Compose 桥接不兼容；本次不把跳过计为通过。

最终动画时间线共 133 帧，窗口 1080×2520、全程保持焦点。键盘首次非零移动出现在请求后 108ms，正文光标首次上移在 125ms，相隔 17ms；键盘动画结束于 540ms，光标底部为 1287px，最终为 1285px，结束后最大差值 2px，没有观察到原先的第二段明显滚动。此处记录的光标位置反映正文移动，起始可见余量也会影响何时需要滚动，不能解释为所有控件零延迟或其他输入法的保证。
