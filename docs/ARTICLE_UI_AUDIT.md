## 已调整的不一致项

| 项目 | 动态编辑器依据 | 图文页本轮调整 |
| --- | --- | --- |
| 页面圆角 | ReplyActivity 顶部 16dp | 共用 EditorAppearance 的 16dp 参数，图文完整页面四角圆角；普通动态原样保留 |
| 控件圆角 | themes.xml 对话框为 12dp | 发布/预览、工具按钮、对话框、题图、正文图片使用 12dp，避免默认胶囊按钮或直角图片混用 |
| 标题栏和发布 | activity_reply.xml 的 16sp 文字发布 | 页头标题、预览、发布使用 16sp 常规字重；发布恢复主题色文字按钮，移除实心色块 |
| 正文字号与行距 | 原生 EditText，14sp、1.2 倍行距 | 正文复用原生输入控件并采用相同参数，移除单独的卡片输入边框 |
| 表情、@ 和话题渲染 | EmojiTextWatcher / FastDeleteAtUserKeyListener | 直接复用，保持自定义表情图片及 @/# 着色、整段快速删除行为 |
| 底部工具 | 现有五项 drawable，24dp 图标、40dp 工具行 | 原顺序、原图标、等宽排列；按压采用相同的 0.92 缩放、70ms 按下、180ms 回弹参数 |
| 可见范围选项 | 左侧 10dp 的“仅自己可见” | 对齐左侧位置，整段标签可点击；图文继续使用自己的可见范围字段 |
| 表情面板 | EmojiPagerAdapter，7 列分页、页码点、退格、三组标签 | 直接复用适配器及资源，移除独立 9 列网格；支持最近表情及长按删除 |
| 主题色与底色 | ReplyActivity 原颜色解析公式 | 原公式提取到 EditorAppearance，两个编辑器共用；包含 Material You 与自定义主题的面板/主色路径，普通动态行为不变 |
| 选中文字与光标 | 原动态主题主色及深色选区 | 复用同一主色及选区颜色公式 |
| 输入法与表情空间 | 原动态扣除导航栏的键盘高度 | 表情与输入法共用一份占用高度，避免切换时叠加；本轮新增高度守恒单元测试 |
| 发布入口菜单 | 使用者指定位置 | 两项细分隔线、右下角对齐 + 中心；保留指向加号的直角，不改成全圆角 |

源文件：`ui/feed/reply/ReplyActivity.kt`、`res/layout/activity_reply.xml`、`res/values/themes.xml`、`res/animator/reply_action_button_scale.xml`，以及 `ui/component/EditorAppearance.kt`、`ui/feed/article/ArticleActivity.kt`、`ArticleParagraphField.kt`、`ArticleEmojiPanel.kt`。

## 仍然保留的界面区别

这些区别对应图文本身的编辑能力，并非再使用一套独立视觉风格：

- 动态是底部短内容面板；图文是可滚动的完整编辑页。图文四角 16dp，普通动态仅顶部两角 16dp。
- 图文有题图、内容标题、预览、图片说明和段落管理；动态没有这些入口。内容标题保留较大粗体，与 16sp 的页面标题分开。
- 图文图片位于正文光标处，图片前后可继续输入；动态保持原有集中附图。
- 图文正文不限为动态输入框的 4–8 行，采用逐段滚动。图文保留按账号自动保存草稿及发布前确认。
